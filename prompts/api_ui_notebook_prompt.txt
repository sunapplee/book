Для каждого пункта задания, относящегося к реализованной части, соблюдай структуру:

— Одна начальная Markdown-ячейка: исходный номер и название пункта, краткое описание задачи, выбранный подход и почему он подходит.
— Одна или несколько кодовых ячеек Python с соответствующим кодом готового приложения. Разные этапы разделяй на ячейки, функцию сохраняй целиком. Если пункт требует демонстрации, добавь HTTP-запросы или укажи действия в интерфейсе и место для скриншота.

Учитывай импорты и зависимости предыдущих ячеек. Указывай, к какому файлу приложения относится код.

Результат выдай одним Python-скриптом на nbformat, который создаёт файл module_notebook.ipynb. Используй отдельные Markdown- и кодовые ячейки, сохраняя описанную структуру.

Включи в скрипт полное содержимое всех ячеек, без сокращений, заглушек и необходимости вручную дописывать текст или код. Корректно экранируй кавычки и переносы строк.

Не придумывай конкретные ответы API, численные результаты проверок и скриншоты. При необходимости добавь демонстрационные запросы и места для скриншотов, продолжая оформление ноутбука. В выводах опирайся на итоговый код, фактические результаты из чата и моё подтверждение работоспособности API.
